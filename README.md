# Predicción de readmisión hospitalaria a 30 días en pacientes diabéticos

Proyecto del curso **Modelos y Simulación de Sistemas II** (Universidad de Antioquia).

**Autores:** Jefferson Stiven Lizarazo Arias · Juan Ricardo Vélez Ciro

## Descripción

Se construyen y comparan modelos de clasificación supervisada para estimar, al momento del alta,
si un paciente diabético será readmitido en **menos de 30 días**. Se usa el dataset
*Diabetes 130-US Hospitals for Years 1999–2008* (101 766 hospitalizaciones, 50 columnas).

- **Clase positiva (1):** `readmitted = "<30"`
- **Clase negativa (0):** `readmitted ∈ {">30", "NO"}`
